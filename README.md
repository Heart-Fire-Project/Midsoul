# 午夜灵魂

> 最后编辑于 v2.2 | 2026/10/10

这里是心火计划的原创非对称竞技地图：**午夜灵魂**的数据包仓库！

## 地图游玩

你可以在 [Releases](https://github.com/Heart-Fire-Project/Midsoul/releases) 直接下载地图或前往 [此页面](https://www.bilibili.com/opus/1195937616442163218) 阅读相关介绍并下载地图。

## 维基站点
如果你想了解更多有关本地图相关的事项，欢迎造访 [午夜灵魂维基站点](https://wiki.hfpro.dev/midsoul/)！

## 帮助我们

若你在游玩过程中发现问题（或有优化意见），欢迎提交 [Issues](https://github.com/Heart-Fire-Project/Midsoul/issues) 或在 [Discussions](https://github.com/Heart-Fire-Project/Midsoul/discussions) 发表你的看法！  
同时，你也可以加入 [午夜灵魂 QQ 群组](https://qm.qq.com/q/5mzL6rr5V6) 进行交流。

### 加入开发

请在加入 [午夜灵魂 QQ 群组](https://qm.qq.com/q/5mzL6rr5V6) 后向管理咨询相关信息。

### 多语言 (i18n)

当前已初步提供英文支持：在 [Releases](https://github.com/Heart-Fire-Project/Midsoul/releases) 中下载 `Midsoul LP` 后将其作为资源包安装，并切换游戏语言即可。

> *部分文本可能不会立即生效，需要重新进入游戏。*  

此外，我们将持续开放 Paratranz 平台的英语翻译，请在 [这里](https://paratranz.cn/projects/17920) 使用口令 `Midsoul-i18n` 来申请加入项目；你也可以选择自主进行各语言的本地化工作，在上方群组中告知管理员就可以将你的翻译加入语言包啦！
